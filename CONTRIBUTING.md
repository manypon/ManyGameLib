# Contributing to ManyGameLib / Как помочь проекту

[English](#english) | [Русский](#russian)

---

## English

Thank you for your interest in ManyGameLib! This project is primarily developed for personal use, but contributions, bug reports, and suggestions are always welcome.

### How to report a bug
If you found a bug, please create a new Issue in the **Issues** tab. Try to describe:
- What you did (steps to reproduce).
- What you expected to happen.
- What actually happened.
- Your OS version and app version (you can see it in the bottom-left corner or in the releases).

### How to suggest a feature
Create a new Issue and use the `enhancement` label. Describe how the feature should work and why it would be useful.

### How to run locally
If you want to fix a bug or add a feature yourself:
1. Install [Node.js](https://nodejs.org) (LTS version).
2. Clone the repository and open the folder.
3. Run `npm install` to install dependencies.
4. Run `npm start` to launch the app in development mode.

### Commits and Pull Requests
Please use [Conventional Commits](https://www.conventionalcommits.org/) for your commit messages (e.g., `feat: add settings menu`, `fix: resolve double launch`, `docs: update readme`).
1. Create a new branch for your changes (`git checkout -b feature/my-new-feature`).
2. Make your changes and test them locally.
3. Create a Pull Request to the `main` branch.

## Русский

Спасибо, что интересуетесь ManyGameLib! Проект в первую очередь разрабатывается для личного использования, но я всегда рад багрепортам, предложениям и помощи с кодом.

### Как сообщить об ошибке
Если вы нашли баг, создайте новый Issue во вкладке **Issues**. Постарайтесь описать:
- Что вы делали (шаги, чтобы повторить ошибку).
- Что должно было произойти.
- Что произошло на самом деле.
- Вашу версию Windows и версию приложения (её видно в левом нижнем углу или в релизах).

### Как предложить новую функцию
Создайте новый Issue и повесьте на него тег `enhancement`. Опишите, как должна работать новая функция и зачем она нужна.

### Как запустить проект локально
Если вы хотите сами исправить баг или добавить функцию:
1. Установите [Node.js](https://nodejs.org) (LTS версию).
2. Склонируйте репозиторий и откройте папку с проектом.
3. Выполните `npm install`, чтобы установить зависимости.
4. Выполните `npm start`, чтобы запустить приложение в режиме разработки.

### Коммиты и Pull Requests
Пожалуйста, используйте [Conventional Commits](https://www.conventionalcommits.org/) для сообщений коммитов (например, `feat: add settings menu`, `fix: resolve double launch`, `docs: update readme`).
1. Создайте новую ветку для ваших изменений (`git checkout -b feature/my-new-feature`).
2. Внесите изменения и протестируйте их локально.
3. Создайте Pull Request в ветку `main`.
