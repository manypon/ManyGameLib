# Contributing to ManyGameLib

Привет! Спасибо, что хочешь помочь с проектом.

## Как запустить локально
1. Установи [Node.js](https://nodejs.org) (LTS версию).
2. Склонируй репозиторий и перейди в папку проекта.
3. Выполни `npm install`, чтобы установить зависимости.
4. Выполни `npm start`, чтобы запустить приложение в режиме разработки.

## Как сообщить об ошибке
Если ты нашел баг, создай новый Issue в разделе **Issues**. Опиши, что произошло, и приложи скриншот, если это возможно.

## Как предложить изменения
1. Сделай форк репозитория.
2. Создай новую ветку (`git checkout -b feature/my-new-feature`).
3. Внеси изменения.
4. Сделай коммит, используя [Conventional Commits](https://www.conventionalcommits.org/) (например, `feat: добавил новую тему`).
5. Отправь изменения и создай Pull Request.
