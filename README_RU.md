# ManyGameLib

[English](README.md) | **Русский**

Локальная библиотека игр для Windows на Electron. Добавляете игру один раз (путь к файлу, иконка, название) и дальше запускаете её из лаунчера.

## Что нужно

**Node.js** (LTS): https://nodejs.org. Компиляторы и Build Tools не нужны.

## Запуск

```powershell
npm install
npm start
```

Или двойной клик по `start.bat`: он сам выполнит `npm install`.

## Сборка готового приложения

Двойной клик по `build.bat`: он закроет запущенное приложение, поставит зависимости, удалит старую сборку и соберёт новую. Или вручную:

```powershell
npm run build
```

Результат: установщик `dist\ManyGameLib-Setup-<версия>.exe` и портативная папка `dist\win-unpacked\ManyGameLib.exe`. Папку `win-unpacked` можно переносить целиком, Node.js для её запуска не нужен.

Если Electron не скачивается (ошибка 504 или сетевая), можно собрать вручную из уже имеющегося Electron: скопируйте его папку `dist` как `ManyGameLib`, переименуйте `electron.exe` в `ManyGameLib.exe`, а в `resources\app` положите `main.js`, `preload.js`, `updater.js`, `zip.js`, `sgdb.js`, `package.json`, `ui` и `build`.

## Как это работает

- При первом запуске библиотека пуста, приложение просит добавить первую игру: **путь к игре**, **иконку** (необязательно) и **название** (подставляется из имени файла или папки).
- Плитки и список, поиск, сортировка, избранное, недавние игры, карточка «Подробнее».
- **Настраиваемый верхний блок.** При добавлении (или потом через «Изменить») выбираете, что показывать вверху библиотеки для игры: фон (размытая обложка, свой баннер или цвет), логотип вместо названия, обложку справа (обрезать по рамке или показать целиком). Предпросмотр обновляется сразу.
- **Время в игре:** считается, пока работает запущенная вами игра (запуски короче минуты не в счёт), показывается в верхнем блоке и в «Подробнее», по нему можно сортировать, а значение можно задать вручную.
- **Перетаскивание:** бросьте в окно `.exe`, `.jar`, `.lnk` и другие файлы игр. Откроется форма добавления с уже заполненными путём, названием и иконкой; несколько файлов идут по очереди.
- **Иконка из файла игры:** для `.exe` и `.lnk` иконка подставляется сама при добавлении игры (или кнопкой «Из файла»); свою картинку можно выбрать всегда.
- **Параметры запуска** у каждой игры (для `.exe`, `.com` и `.jar`), например `-windowed -nolauncher`.
- **Меню игры:** кроме запуска, избранного, «Подробнее» и «Изменить», в нём есть «Показать в папке» (открывает проводник на файле игры) и «Копировать путь».
- **Теги:** задайте игре свои теги («Пройдено», «В планах», «Онлайн»…) в её форме; боковое меню показывает их с числом игр, клик фильтрует библиотеку (несколько тегов: игры со всеми). Правая кнопка по тегу переименовывает или удаляет его.
- **Изменение игры** в любой момент: название, путь, иконка, баннер, логотип и настройки верхнего блока (правая кнопка мыши по игре или «Подробнее», затем «Изменить»).
- **Поиск обложек:** кнопка «Найти в SteamGridDB» в форме игры находит обложки, баннеры, логотипы и иконки (нужен ваш собственный бесплатный ключ SteamGridDB, он хранится на компьютере в зашифрованном виде).
- Клавиатура: Tab переходит между играми, Enter запускает, пробел выбирает.
- **Запуск:** кнопка «Запустить», кнопка на плитке при наведении, двойной клик или правая кнопка мыши. Пока игра идёт, её кнопка показывает «Играет», и запустить её второй раз нельзя.
- **Трей:** крестик окна спрашивает, свернуть приложение в трей или закрыть (с флажком «Запомнить выбор», меняется в настройках). Автозапуск может открывать приложение сразу в трее.
- **Страница настроек:** фон приложения (встроенная картинка, своя или без неё) с ползунками размытия и затемнения, возможность отключить карточку верхнего блока, автозапуск с Windows, необязательный файл журнала и свой путь к Java для `.jar`. Фоном приложения может быть анимированная GIF (до 40 МБ).
- **Обновления:** приложение проверяет GitHub на новую версию (это можно выключить в настройках). Установленная через установщик версия скачивает и ставит обновление по вашей кнопке, а портативная папка только подсказывает страницу релиза.
- **Профиль:** страница с ником, аватаром (хранится только на этом компьютере), датой «в библиотеке с…» и статистикой: всего наиграно, за 7 и 30 дней, топ игр и график по дням. Периоды считаются по журналу игровых сессий, который ведётся с этой версии; время, наигранное раньше, учитывается только в общей сумме. Ниже 28 встроенных достижений (размер библиотеки, часы, сессии, серии дней, теги, трей, экспорт и другое): неполученные серые, с условием и прогрессом, а при получении появляется уведомление.
- Поддерживаются `.exe`, `.jar` (запускается через Java, она должна быть установлена; приложение ищет `javaw` в PATH, `JAVA_HOME`, реестре Windows и обычных папках Program Files), ярлыки `.lnk` и `.url`, а также `.bat`, `.cmd`, `.msi`. Любой другой файл откроется программой, назначенной ему в Windows.
- **Стеклянное оформление** («Настройки → Внешний вид», по умолчанию выключено): плавающие полупрозрачные боковая панель и верхняя строка, стеклянные карточки, окна и уведомления; без своего фона за стеклом мягкие цветные пятна.
- У каждой игры может быть статус прохождения (не начата / играю / пройдена, значок на плитке) и своя заметка.
- Игры стартуют в своей папке или в рабочей папке, которую вы выберете для игры. Если нужны права администратора, Windows покажет запрос UAC; игру также можно всегда запускать от имени администратора (время в игре при этом считается).
- «Убрать из библиотеки» ничего не спрашивает: игра уходит в корзину на 30 дней, а в уведомлении есть кнопка «Отменить» («Настройки → Библиотека» вернёт её позже или удалит окончательно). Файлы игры не трогаются.
- Если файл игры переместили или удалили, на плитке появится метка «Файл не найден».

## Где лежат данные

`%USERPROFILE%\manypon\manygamelib\`

- `games.json` — список игр
- `icons\` — копии выбранных иконок (если исходный файл удалят, иконка останется)
- `profile.json`: ваш ник и имя файла аватара; `sessions.json`: журнал игровых сессий (когда и сколько); `settings.json`: ваши настройки (копия своего фона лежит в `icons\`); `trash.json`: убранные за последние 30 дней игры; `secrets.json`: ключ SteamGridDB, зашифрованный Windows, только если вы его добавили; `logs\`: журнал, только если вы его включили
- `games.json.bak`: предыдущая версия списка, обновляется при каждом сохранении
- `backups\`: по одной копии списка за каждый запуск приложения, хранятся последние 5
- Если `games.json` повредится, он переименуется в `games.corrupt-<дата>.json` (не перезаписывается), а последняя рабочая копия восстановится автоматически с уведомлением.
- Если файл занят другой программой, приложение предложит «Повторить» или «Выйти», а не запустится с пустой библиотекой.

Чтобы перенести библиотеку на другой компьютер, используйте **«Настройки → Библиотека → Экспорт / Импорт»** (ZIP с играми и их картинками; импорт добавляет игры и пропускает те, что уже есть) или скопируйте эту папку целиком. Пути к играм в ней абсолютные, поэтому игры должны лежать по тем же путям.

Если раньше использовалась версия GameLib (данные в `%APPDATA%\gamelib`), при первом запуске библиотека скопируется в новое место автоматически. Старая папка остаётся нетронутой.

## Иконки и обложки

Лучше всего квадрат 512×512 или вертикальная обложка 600×900 (PNG, JPG, WEBP, ICO, BMP, GIF), размер файла до 8 МБ. Картинка обрезается по центру под плитку.

Для верхнего блока: баннер примерно 1920×620 и логотип в PNG с прозрачным фоном (на экране до 520×130).

## Структура

```
manygamelib/
├─ main.js        хранение игр, запуск процессов, диалоги выбора файлов
├─ preload.js     безопасный мост между интерфейсом и main.js
├─ updater.js     проверка, скачивание и установка обновлений
├─ zip.js         чтение и запись ZIP для экспорта и импорта библиотеки
├─ sgdb.js        поиск обложек в SteamGridDB
├─ ui/            интерфейс (index.html, style.css, app.js, assets/)
├─ build/         иконки приложения
├─ docs/          техническая документация
├─ start.bat      запуск двойным кликом
└─ build.bat      сборка двойным кликом
```
