# Поиск обложек (SteamGridDB)

[English](sgdb.md) | [Русский](sgdb_RU.md)

[← Оглавление документации](README_RU.md)

Кнопка «Найти в SteamGridDB» в форме игры ищет на [SteamGridDB](https://www.steamgriddb.com) обложки, баннеры, логотипы и иконки. Код в `sgdb.js` (подключается из `main.js`), окно это `openSgdbPanel` в `ui/app.js`.

## Ключ API

SteamGridDB требует личный ключ. Он бесплатный: зарегистрируйтесь на сайте и скопируйте ключ из профиля («Preferences → API»). Приложение не поставляется с ключом, а ключ ни в коем случае нельзя коммитить в репозиторий.

- Ключ вставляется в окне поиска (при его отсутствии оно спросит) или в «Настройки → Библиотека → SteamGridDB».
- Хранится в `secrets.json` в папке данных, **зашифрованный через Electron `safeStorage`** (в Windows это DPAPI: расшифровать его может только ваша учётная запись Windows). Если шифрование недоступно, ключ не сохраняется вообще.
- Лежит отдельно от `settings.json`, поэтому не затрагивается сбросом настроек и не входит в экспорт библиотеки ([Перенос библиотеки](transfer_RU.md)).
- Страница ключ не видит. Команда `sgdb_state` сообщает только `{ hasKey }`. В журнал ключ тоже не пишется.
- Новый ключ проверяется пробным запросом. Ключ, который SteamGridDB отклонил (401 или 403), не сохраняется. Если связи нет, ключ сохраняется, а приложение сообщает, что проверить его не удалось.
- «Удалить ключ» в настройках удаляет файл.

## Что делает поиск

1. `sgdb_search { term }`: `GET /search/autocomplete/<название>`, до 12 игр.
2. `sgdb_images { gameId, kind }`: `GET /<раздел>/game/<id>`, до 36 картинок с `url`, `thumb`, размером и стилем.

| Вкладка | Раздел API | Какое поле заполняет |
|---------|------------|----------------------|
| Обложка | `grids` (600×900, 342×482, 660×930) | иконка или обложка |
| Баннер | `heroes` | баннер |
| Логотип | `logos` | логотип |
| Иконка | `icons` | иконка или обложка |

NSFW и юмор всегда выключены, запрашиваются только PNG, JPEG и WEBP (для логотипов и иконок PNG и WEBP). Окно открывается уже с поиском по названию из формы, первый результат выбирается сам.

3. Клик по картинке запускает `sgdb_download { url }`. Главный процесс скачивает её во временный файл (`manygamelib-sgdb` во временной папке системы; старые файлы удаляются при следующем скачивании и при запуске) и возвращает путь и превью. Дальше форма обращается с ней точно как с файлом, выбранным кнопкой «Обзор…»: в `icons\` картинка копируется только при сохранении игры и с обычными проверками (тип, 8 МБ). Если форму закрыть без сохранения, в библиотеку ничего не попадёт.

## Безопасность

- Все сетевые запросы делает главный процесс. Страница может вызвать только шесть команд из белого списка.
- Скачивать можно только адреса `https` на `steamgriddb.com` и его поддоменах. Это проверяется для каждого адреса из списка и ещё раз при скачивании (похожие адреса вроде `steamgriddb.com.evil.com` или `steamgriddb.com@evil.com` отклоняются). Перенаправления не выполняются.
- Ключ отправляется только в API (`Authorization: Bearer …`). При скачивании картинки с CDN он не передаётся.
- Тип файла определяется по первым байтам (PNG, JPEG, WEBP, GIF), а не по словам сервера. Страница, не являющаяся картинкой, и файл больше 8 МБ отклоняются.
- CSP страницы разрешает миниатюры только с `https://*.steamgriddb.com` (`img-src 'self' data: https://*.steamgriddb.com`). Ничего другого из интернета в страницу загрузить нельзя.
- Таймауты: 15 секунд для API, 30 для картинки. Ошибки показываются понятными словами: нет ключа, ключ отклонён, слишком много запросов, нет связи, нет ответа вовремя.

## Ограничения

- Картинки принадлежат своим авторам и SteamGridDB. Окно подсказывает, откуда они; если делитесь библиотекой, посмотрите условия сайта.
- Поиску нужны интернет и работающий SteamGridDB. Остальное приложение работает без них.
